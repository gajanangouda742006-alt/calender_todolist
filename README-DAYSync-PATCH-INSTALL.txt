# DaySync patch – Weather/Reset headers, goal confirmation, iOS preparation

## Extract location

Extract this ZIP directly into the existing project root:

`P:\MyProjects\calender_todolist`

The ZIP contains project-relative paths. Allow the listed files to overwrite existing files. Do not extract into a nested `calender_todolist` folder.

## Changes included

- `app.js`: goal deletion now uses the existing DaySync confirmation dialog (`Cancel` / `Delete`) and keeps the warning that the goal's progress history is also deleted. The existing `saveGoalAchievements` persistence path is retained.
- `style.css`: gives Weather and Reset Options compact rounded raised headers matching the DaySync 3D header treatment.
- `package.json`: adds `ios:prepare` and `ios:open` commands.
- `scripts/prepare-ios.js`: creates the Capacitor iOS platform if it is missing, stages the existing web app, syncs Capacitor plugins, and adds the iOS permission descriptions for location and optional voice input.

## Rebuild the web bundle on Windows

The project ZIP excludes `node_modules`, so run:

```powershell
cd P:\MyProjects\calender_todolist
npm ci
node --check .\app.js
node .\scripts\build-web.js
npm start
```

The app should then be tested in the browser before making a mobile build.

## Prepare the iOS project

Set the HTTPS API origin and run:

```powershell
cd P:\MyProjects\calender_todolist
$env:SAHRA_API_BASE_URL = "https://calender-todolist.onrender.com"
npm run ios:prepare
```

If the iOS platform is created successfully, its project will be under `ios\`. You can prepare/sync the Capacitor project from Windows, but **building, signing, simulator testing, and installing on a physical iPhone require macOS with Xcode**. On a Mac, open `ios/App/App.xcworkspace`, select your Apple development team, configure the bundle identifier/signing, then build and run on an iPhone.

For later syncs after web changes:

```powershell
$env:SAHRA_API_BASE_URL = "https://calender-todolist.onrender.com"
npm run ios:prepare
```

## Important preservation notes

- No MongoDB schemas, backend routes, account data, offline queue logic, or synchronization logic are intentionally changed.
- The existing Android project is not replaced.
- The patch does not contain or replace your original intro video. Keep `assets\app-intro.mp4` and existing media in place.
- The iOS project is generated by Capacitor from your installed project dependencies; the ZIP cannot include a prebuilt signed iPhone app. iOS runtime behavior still needs to be validated on a Mac/iPhone, especially location, speech recognition, notifications, and any plugin-specific flows.
