DaySync Goal Delete Confirmation Page

Modified files:
- app.js
- style.css

The goal Delete button now navigates to a dedicated confirmation page inside DaySync. The page shows the goal name, progress-entry count and XP, and offers Cancel and Delete Goal actions. The existing saveGoalAchievements persistence/synchronization path and reminder cancellation are retained.

Install:
1. Back up app.js and style.css in your project.
2. Copy these two files into P:\MyProjects\calender_todolist, replacing the existing files.
3. Open PowerShell in P:\MyProjects\calender_todolist and run:

   node --check app.js
   node scripts/build-web.js

4. If the app is running, restart it and hard-refresh the browser with Ctrl+Shift+R.
5. For Android, run your existing mobile staging/sync commands and rebuild the app.

Note: web-app.js is generated by scripts/build-web.js and was not included because this build environment did not have the project's esbuild dependency installed. Run the build command above in your project, where dependencies are installed, to regenerate it.
