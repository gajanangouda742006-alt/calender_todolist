DaySync Expense Tracker Mobile Header Fix
=========================================

Changed file:
- style.css

What changed:
- The Expense Tracker dashboard header now uses position: sticky inside the app's
  main scrolling area, instead of viewport-fixed positioning that could move
  unexpectedly inside the mobile frame.
- Removed the extra reserved top padding that was only needed for the old fixed
  header.
- Scoped all overrides to the Expense Tracker dashboard so other pages are untouched.
- Added safe-area-aware top spacing for mobile devices.

Install:
1. Back up P:\MyProjects\calender_todolist\style.css.
2. Extract this ZIP into P:\MyProjects\calender_todolist and replace style.css.
3. Rebuild the web bundle only if your normal build process copies CSS separately;
   CSS itself is loaded directly from style.css by the app.
4. Test by opening Expense Tracker and scrolling its content on a phone.

No JavaScript, database, alarm, calendar, assistant, or other page files were changed.

Note:
This is a source-level CSS fix. It has not been tested on a physical Android or iOS device.
