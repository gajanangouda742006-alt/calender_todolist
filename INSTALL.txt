DaySync patch installation
==========================

Files in this patch:
- app.js
- style.css

Install:
1. Back up P:\MyProjects\calender_todolist\app.js and style.css.
2. Extract this ZIP into P:\MyProjects\calender_todolist and replace only these two files.
3. Open PowerShell and run:

   cd P:\MyProjects\calender_todolist
   node --check .\app.js
   node .\scripts\build-web.js

4. For Android, stage and sync the updated web bundle using your existing workflow:
   npm run mobile:stage
   npx cap sync android

5. For iOS, on macOS with Xcode:
   npm run mobile:stage
   npx cap sync ios

Notes:
- Alarm hour/minute/AM-PM controls remain native HTML select elements for accessibility and platform picker behavior, but now have a raised 3D selector appearance.
- Weather and Reset Options headers use a compact raised common-header style.
- This patch does NOT implement a native full-screen lock-screen alarm activity. The current project uses Capacitor local notifications; a full-screen Android alarm needs native AlarmManager/Activity integration and full-screen-intent permission handling. iOS does not generally permit arbitrary third-party full-screen lock-screen UI. Do not treat this visual patch as completing that separate native alarm requirement.
- Test on real Android/iOS devices after building.
