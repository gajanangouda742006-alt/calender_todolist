DaySync focused mobile UI and alarm interaction patch
=====================================================

Included source files:
- app.js
- style.css
- pages/notepad.js
- mobile-notifications.js

Install
-------
1. Back up your project.
2. Extract these files into P:\MyProjects\calender_todolist, preserving folders.
3. Replace only the included files.
4. Run:
   node --check .\app.js
   node --check .\pages\notepad.js
   node --check .\mobile-notifications.js
   node .\scripts\build-web.js
5. For Android:
   npm run mobile:stage
   npx cap sync android
   cd android
   .\gradlew.bat assembleDebug

Notes and limitations
---------------------
- Notepad search now filters existing note cards in place. It does not replace the input element on every keystroke, preventing the keyboard focus loss/blink issue.
- Goal deletion uses the existing DaySync confirmation dialog.
- Calendar Add Event already uses the existing entry modal over the current page; that behavior is preserved.
- Weather/reset headers, general page headers, calendar header, task filters, and finance headers receive mobile sticky/alignment overrides.
- The alarm overlay with Dismiss and 5-minute Snooze is shown after the user taps the scheduled alarm notification and DaySync opens. This is NOT a native Android full-screen lock-screen activity. The Capacitor Local Notifications plugin used by this project does not by itself guarantee full-screen lock-screen presentation.
- iOS does not guarantee arbitrary full-screen lock-screen UI for third-party apps. Alarm sound/notification delivery remains subject to OS permissions, focus/silent settings, sound resource limits, and platform policy.
- Android status-bar time/battery/network icon contrast is controlled by the native OS status bar and Capacitor StatusBar configuration, not ordinary page CSS. Test on a real device; this patch does not claim to override OS status-bar appearance on every Android skin.
- No database schema, user data, backend, or native Android project files are changed.
